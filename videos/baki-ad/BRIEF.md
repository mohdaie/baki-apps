# Baki — 30s social ad

## Intent
Problem → solution → features → CTA.

1. **Payday (0–3.6s)** RM 4,200 lands, bank/e-wallet alerts start eating it.
2. **Problem (3.6–7s)** Two weeks later: RM 312. "Where did it all go?"
3. **Pain (7–10s)** Budget apps make you type every expense. "Nobody keeps that up."
4. **Solution (10–12.5s)** Meet Baki. The budget that fills itself.
5. **01 Auto-capture (12.5–16.5s)** Bank alert → review card → one tap Save → Activity.
6. **02 Left to spend (16.5–20s)** Salary − bills − spent = RM 1,284.60; available today.
7. **03 Commitments (20–23.5s)** Bills ticked paid come off first.
8. **04 Private (23.5–26s)** No internet access, no account, no cloud.
9. **CTA (26–30s)** Baki · Know what's left. Every day. · Get Baki for Android.

## Assets
- Music: original synthesized bed (`assets/audio/bgm.mp3`), 120 BPM, drop at 10s.
- SFX: HyperFrames bundled library (Pixabay Content License).
- Brand: colors and wallet icon taken from the app (`Theme.kt`, `ic_launcher_foreground.xml`).
